实现一个简单的成绩等级判断程序。

请在当前工作区创建 `score.py`，实现函数：

    classify_score(score)

规则：

- 90 到 100：返回 "A"
- 80 到 89：返回 "B"
- 60 到 79：返回 "C"
- 0 到 59：返回 "D"
- 小于 0 或大于 100：抛出 ValueError
- 输入必须是数字，否则抛出 TypeError

请同时创建 `test_score.py`，测试以下情况：

1. 95 返回 "A"
2. 85 返回 "B"
3. 70 返回 "C"
4. 50 返回 "D"
5. 0 和 100 是合法边界
6. -1 和 101 抛出 ValueError
7. 字符串输入抛出 TypeError

执行过程必须遵守：

1. 先查看当前工作区。
2. 实现代码和测试。
3. 使用 verify_task 执行：
   python -m unittest -v test_score.py
4. 如果测试失败，分析失败原因并修改代码，然后重新执行 verify_task。
5. 测试通过前，不要调用 finish_task，也不要声称任务完成。
6. 测试通过后，调用 finish_task，总结修改的文件和测试结果。
